# An AVR128DB48 board

A self-built board around an **AVR128DB48** (48-pin, 128 KB flash,
16 KB SRAM), the bench chip of the `avrdx/` stratum. Design files: a
repository in preparation.

- **Clock**: 24 MHz crystal on PA0/PA1 (those two pins are not GPIOs
  here); no 32 kHz crystal - the RTC and the kernel tick run on the
  internal OSC32K, PF0/PF1 free.
- **Supply**: jumper-selectable 3.3 V / 5 V; VDDIO2 powered, so PORTC
  (the MVIO domain) is usable and could talk 3.3 V logic while the
  rest of the chip runs at 5 V.
- **Console**: a CH340 bridge on USART2 ALT1, PF4 (TX) / PF5 (RX);
  460800 in the console apps. The CH340 has no USB serial, so the
  console is addressed by `/dev/serial/by-path`.
- **Probe**: an Atmel-ICE over UPDI on a 6-pin ISP header (pin 2 VCC,
  pin 5 UPDI, pin 6 GND) - [../probes/atmel-ice.md](../probes/atmel-ice.md).
- **Identity**: a label in the USERROW, written once over UPDI and
  printed by every suite's banner
  ([../avrdx/userrow.md](../avrdx/userrow.md)).
- **Provisioning for the storage suites**: fuses BOOTSIZE = 128 and
  CODESIZE = 0 (all code in the BOOT section, the rest of the flash
  free for `NvHeap`), written with `brio fuses <board> bootsize=128`;
  [../avrdx/nvm.md](../avrdx/nvm.md) says why.
- Manifest type `db48`; the same design in a 28- or 32-pin part would
  be `db28` / `db32`.
